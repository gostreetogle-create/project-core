# Бизнес-логика — Управление производством

> **Версия:** 1.0 · 2026-06-01
> **Что это:** Описание ВСЕХ бизнес-процессов на человеческом языке. Без кода, без технологий — только смысл.
> **Когда понадобится:** после того как ядро готово. Тогда проходим по пунктам и реализуем.

---

## Общая картина

Система ведёт товар от заказа клиента до отгрузки с производства.

```
ЗАКАЗ → ПРОИЗВОДСТВО → СКЛАД → ОТГРУЗКА
(продали)  (сделали)   (храним)  (отправили)
```

На каждом этапе свои сотрудники, свои документы, свои правила.

---

## Часть 1: ПРОДАЖИ

### 1.1 Товары и услуги
Что продаём:
- Название, артикул
- Тип: товар / услуга / работа
- Цена
- Категория (в какой группе лежит)
- Фотографии
- Единица измерения (штуки, метры, килограммы…)
- Характеристики (размеры, материал, цвет…)

### 1.2 Клиенты (контрагенты)
Кому продаём:
- Название организации или ФИО
- ИНН, КПП, банковские реквизиты
- Роль: клиент / поставщик / наша компания / всё вместе
- Контакты (телефон, email, адрес)

### 1.3 Коммерческое предложение (КП)
Документ для клиента:
- Список товаров с ценами
- Условия (сроки, доставка, гарантия)
- Наша компания (реквизиты, логотип, фон бланка)
- Клиент (кому)
- Номер КП, дата

**Статусы КП:**
```
Черновик → Отправлено → Принято
                      → Отклонено → Черновик (новая версия)
```

**Что можно делать:**
- Менять состав (добавить/убрать товары) — только в Черновике
- Менять цены, наценку, скидку
- Скачать PDF (красивый документ)
- Отправить ссылку клиенту (гостевой доступ — без пароля)

### 1.4 Заказы клиентов
Когда клиент согласился:
- Номер заказа
- Какое КП (связь)
- Список позиций с количеством
- Статус заказа (принят → в работе → готов → отгружен)
- Планируемая дата готовности

## Часть 2: ПРОИЗВОДСТВО

### 2.1 Спецификации изделий (BOM)
Из чего состоит изделие:
- Список материалов и их количество
- Список операций (что нужно сделать)
- Чертежи, схемы
- Нормы времени

### 2.2 Технологические операции
Какие шаги нужны для производства:
- Название операции (резка, сварка, покраска…)
- Оборудование
- Норма времени
- Последовательность (что за чем)

### 2.3 Техпроцессы (маршрутные карты)
Полная цепочка операций для изделия:
- Список операций по порядку
- Для каждой: время, оборудование, исполнитель

### 2.4 Наряды на производство
Задание для цеха:
- На какой заказ
- Какое изделие
- Какие операции выполнить
- Кто исполнитель
- Плановая дата
- Статус выполнения

### 2.5 Диаграмма Ганта (план работ)
Визуальное отображение:
- Все заказы на шкале времени
- Кто чем занят
- Что пересекается, что задерживается

---

## Часть 3: СКЛАД

### 3.1 Склады
Где храним:
- Название склада
- Адрес
- Ответственный

### 3.2 Материалы и остатки
Что есть в наличии:
- Какой материал / товар
- В каком количестве
- На каком складе
- Минимальный запас (когда пора заказывать)

### 3.3 Движения склада
Что происходит с материалами:
- Приход (закупили, произвели)
- Расход (отгрузили, списали в производство)
- Перемещение (между складами)
- Резервирование (забронировано под заказ)

### 3.4 Заявки на закупку
Когда материалов не хватает:
- Какой материал нужен
- Сколько
- Для какого заказа
- Кто утверждает

### 3.5 Заказы поставщикам
Когда заявка утверждена:
- У какого поставщика закупаем
- Что, сколько, по какой цене
- Ожидаемая дата поставки

---

## Часть 4: ОТГРУЗКА

### 4.1 Отгрузки
Когда заказ готов к отправке:
- Какой заказ
- Какие позиции отгружаем
- Дата отгрузки
- Способ доставки

### 4.2 Отгрузочные документы
Что печатаем:
- Товарная накладная
- Счёт-фактура
- Акт выполненных работ
- Транспортная накладная

---

## Часть 5: СЕБЕСТОИМОСТЬ

### 5.1 Калькуляция (плановая)
Сколько БУДЕТ стоить производство:
- Материалы (по ценам закупки)
- Работа (по нормо-часам)
- Накладные расходы (аренда, электричество…)

### 5.2 Фактические затраты
Сколько РЕАЛЬНО стоило:
- Фактический расход материалов
- Фактическое время работы
- Отклонения от плана

---

## Часть 6: АДМИНИСТРИРОВАНИЕ

### 6.1 Пользователи и роли
Кто работает в системе:
- **Администратор** — всё может
- **Менеджер** — продажи, клиенты, КП
- **Производственник** — наряды, операции
- **Кладовщик** — склад, материалы
- **Наблюдатель** — только смотрит

### 6.2 Настройки системы
Общие параметры:
- Название компании
- Валюта (рубли)
- НДС (сколько процентов)
- Срок действия КП (дней)
- Шаблоны документов (бланки)

### 6.3 Статусы
Гибкая настройка статусов для любой сущности:
- Название статуса (Черновик, В работе, Готово…)
- Цвет метки
- Какие переходы разрешены (из Черновика → можно в Отправлено, нельзя сразу в Готово)
- Какой статус начальный, какой конечный

## Порядок реализации (этапы)

| Этап | Что делаем | Почему сначала это |
|------|-----------|-------------------|
| **1** | Товары, Клиенты, КП, Авторизация | Это ядро CRM — без него ничего не работает |
| **2** | Заказы, Статусы | Клиенты заказывают — мы отслеживаем |
| **3** | Спецификации, Операции, Техпроцессы | Начинаем производство |
| **4** | Наряды, План (Гант) | Управляем производством |
| **5** | Склады, Движения, Остатки | Учёт материалов |
| **6** | Закупки, Поставщики | Пополнение склада |
| **7** | Отгрузки, Документы | Закрытие заказа |
| **8** | Себестоимость (план/факт) | Анализ прибыльности |
| **9** | AI-аналитика, Дашборды | Умные подсказки и отчёты |

## Post-Core: Инструменты разработчика / Админ-панель

Эти фичи — следующий этап после того как ядро готово. Они не входят в минимальное ядро, но нужны для удобной работы.

### 1. Универсальная CRUD таблица с выбором полей из БД

**Идея:** Таблица, которая подключается к существующей коллекции MongoDB и автоматически строит колонки по её схеме.

```
/admin/tables/products → показывает таблицу товаров
/admin/tables/orders  → показывает таблицу заказов
```

**Поля:**
- Выбор коллекции из выпадающего списка
- Авто-определение полей (name → текст, price → число, status → бейдж)
- CRUD: создать, редактировать, удалить, копировать
- Поиск, сортировка, пагинация

**Статус:** P2 (после ядра)

### 2. Конструктор таблиц (Builder)

**Идея:** Визуальный конструктор: выбрал коллекцию → выбрал поля → назвал таблицу → сохранил. Готовая таблица вставляется в любую страницу.

**Как работает:**
1. Заходишь в "Конструктор таблиц"
2. Выбираешь коллекцию из БД (выпадающий список)
3. Выбираешь поля (наименование, цена, статус...)
4. Нажимаешь "Сохранить"
5. Таблица доступна для вставки в текстовый редактор

**Статус:** P3 (после CRUD таблицы)

### 3. Текстовый редактор с вставкой таблиц

**Идея:** WYSIWYG редактор (TinyMCE/Quill/PrimeNG Editor), который умеет вставлять сохранённые таблицы как живые блоки.

**Статус:** P3

## Что требует уточнения

По каждому разделу выше есть детальные вопросы. Пройдём когда будем готовы.

Примеры:
- **Товары:** Какие именно характеристики? Размеры, материал, цвет — что ещё?
- **КП:** Какой бланк? Только текст или с фоном? Какие условия прописываем?
- **Производство:** Реальное производство (станки, цеха) или сборка из готового?
- **Склад:** Один склад или несколько? Адресное хранение (стеллаж, полка)?
- **Себестоимость:** Какие накладные расходы учитываем?
